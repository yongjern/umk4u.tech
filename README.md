# UMK4U

The main product website for independent, student-focused tools built around life at Universiti Malaysia Kelantan.

## Products

- [UMKWifi](https://wifi.umk4u.tech) - campus Wi-Fi setup and troubleshooting.
- [MyUMK](https://my.umk4u.tech) - a focused companion for student information and academic shortcuts.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

Run `npm run build` to create a production build.
